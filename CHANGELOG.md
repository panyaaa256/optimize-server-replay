Adds an option to pause a Flashback chunk recording when nothing changes in its area for a while. Your `config.json` does not have the new keys, so the mod logs a warning for each and uses its default (off) until you add them.

- Add `pause_when_idle_seconds`, off by default. It pauses a recording when the blocks and entities in its area have not changed for that many seconds, and resumes it when something changes, so that a player left idle in the area no longer keeps an empty recording going. `idle_ignore_entities` and `idle_entity_whitelist` choose which entities count as a change; by default only players do, and players in spectator mode never do ([#7](https://github.com/panyaaa256/optimize-server-replay/pull/7))
